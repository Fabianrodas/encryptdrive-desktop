## Scope and evidence limits

This resolution addresses all 11 P1 findings in the external audit summary pasted into the task. The summary reports no P0 findings. The original `UX3_INDEPENDENT_EXTERNAL_AUDIT_R1.md` file was not present in this repository, so the finding titles and acceptance language below are transcribed from that summary; original auditor line references could not be checked.

Only `encryptdrive-desktop` source and documentation were changed. The Java and private documentation repositories were not modified. No real files, vaults, credentials, or cryptographic material are used by the preview.

The latest preview release was built and launched with `Start-Process`; PID 15416 was still alive after five seconds, with empty captured stdout/stderr. Live visual checks, Narrator, UI Automation tree, High Contrast, and interactive DPI checks remain **BLOCKED / NOT RUN**. Source and unit-test results are not presented as substitutes for those checks.

## R2 manual validation checklist

1. Rebuild/launch `target/release/encryptdrive-desktop.exe --design-preview`; record the executable hash and confirm it stays open offline.
2. Capture the same 1180×792 logical window in Light and Dark. Capture the shell at 960×640 as well. Keep screenshots genuine and label theme, size, DPI, and executable hash.
3. In Files, compare table top position before and after selecting the first row. Click a row, double-click a folder, double-click a file, sort while a lower row is focused, and then scroll manually.
4. Verify single/Ctrl/Shift selection, Ctrl+A on filtered results, Arrow/Home/End/Page Up/Page Down/Space, Tab/Shift+Tab stop order, Enter, Escape, F2, Delete, Shift+F10, Alt+Left, and Alt+Up.

7. Inspect focus, selected, hovered, disabled, and dialog states at 100%, 150%, and 200% Windows scaling and in High Contrast. Inspect the UI Automation/AccessKit tree and test with Windows Narrator. Record each unavailable check as NOT RUN with the tool/reason.
