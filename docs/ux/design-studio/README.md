# Phase 1A-UX design studio

This folder records the Phase 1A-UX research and the UX3 design-system and branding iteration. UX3 is implemented in the native eframe shell and its opt-in synthetic preview. It is a source-reviewed candidate, not a visually accepted design.

- [Product visual direction](PRODUCT_VISUAL_DIRECTION.md) — implemented structure, preview boundary, and remaining gates.
- [Design research](DESIGN_RESEARCH.md) and [competitive analysis](COMPETITIVE_ANALYSIS.md) — traceable references and transfer/rejection rationale.
- [Decision register](DESIGN_DECISION_REGISTER.md), [Design System V2](DESIGN_SYSTEM_V2.md), and [Design System V3](DESIGN_SYSTEM_V3.md) — historical choices and the current token system.
- [Screen/state matrix](SCREEN_STATE_MATRIX.md) and [component inventory](COMPONENT_INVENTORY.md) — implemented source coverage and evidence status.
- [Interaction/accessibility review](INTERACTION_AND_ACCESSIBILITY_REVIEW.md) — keyboard/model evidence and unrun accessibility checks.
- [Iteration log](ITERATION_LOG.md), [critic review](CRITIC_REVIEW.md), and [visual acceptance report](VISUAL_ACCEPTANCE_REPORT.md) — review results and limitations.
- [UX3 iteration log](UX3_ITERATION_LOG.md), [UX3 internal critic](UX3_INTERNAL_CRITIC.md), [external review packet](UX3_EXTERNAL_REVIEW_PACKET.md), and [external critic result](UX3_EXTERNAL_CRITIC_RESULT.md) — independent source reviews and their limits.
- [UX3 final visual report](UX3_FINAL_VISUAL_REPORT.md) and [UX3 owner review guide](UX3_OWNER_REVIEW_GUIDE.md) — current evidence boundary and reproducible manual checks.
- [R3 remediation matrix](UX3_R3_REMEDIATION_MATRIX.md), [regression-test report](UX3_REGRESSION_TEST_REPORT.md), [Release candidate identity](UX3_RELEASE_CANDIDATE_REPORT.md), and [manual R3 validation matrix](UX3_MANUAL_R3_VALIDATION_MATRIX.md) — current source/test evidence and owner-only live checks.
- [R2 defect register](UX3_R2_REMEDIATION_MATRIX.md) and [Claude R3 review packet](UX3_CLAUDE_R3_REVIEW_PACKET.md) — historical evidence; neither replaces the current R3 matrix.
- [External audit source register](external-audits/README.md) — records which original review files were and were not supplied.
- [Typography](TYPOGRAPHY_SPEC.md), [iconography audit](ICONOGRAPHY_AUDIT.md), [icon mapping](ICON_MAPPING.md), [theme and contrast audit](THEME_AND_CONTRAST_AUDIT.md), [brand provenance](BRAND_ASSET_PROVENANCE.md), [UI copy audit](UI_COPY_AUDIT.md), and [component standardization](COMPONENT_STANDARDIZATION.md).

See [Phase 1A-UX formal closeout](PHASE_1A_UX_CLOSEOUT.md) for the decision, evidence links, scope exclusions, and remaining verification gates.
